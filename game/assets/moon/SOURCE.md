# Lunar surface source

Unmodified NASA Scientific Visualization Studio CGI Moon Kit color map, 1024×512 JPEG.

Source: https://svs.gsfc.nasa.gov/4720/
Asset: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_poles_1k.jpg
Credit: NASA's Scientific Visualization Studio; Lunar Reconnaissance Orbiter Camera data.

The game uses the real lunar surface map, a restrained halo and a larger full disk. No generated lunar detail or image processing was used.
